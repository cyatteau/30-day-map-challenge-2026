# 🗺️ 30 Day Map Challenge 2026

## One Map That Grows

**One application. 30 days. 30 mapping experiments.**

For the 2026 #30DayMapChallenge, I'm incrementally building a single web mapping application using the ArcGIS Maps SDK for JavaScript.

Each day introduces a new mapping experience inspired by the daily challenge theme, while showcasing SDK capabilities, recent releases, map components, and modern web development techniques.

Rather than creating 30 independent maps, each day's contribution builds upon the previous days, creating an interactive application that grows throughout November.

## 🌐 Explore the Maps

Days 1–22 were originally published on CodePen. Starting with Day 23, the project moved to GitHub to accommodate the growing application's size and complexity.

Each HTML file contains the complete application as of that day, including all previous mapping experiments. Use the navigation buttons within the application to explore earlier days.

## 💻 Run Locally

Each daily application is contained within a single HTML file, including its HTML, CSS, and JavaScript.

No build tools, frameworks, or package installations are required.

1. Clone or download this repository.
2. Open the HTML file for the day you'd like to explore.
3. Configure your ArcGIS API key where required.
4. Serve the file using a local development server.

An internet connection is required to load the ArcGIS SDK and associated mapping resources.

## 🎯 Project Goals

- Explore creative approaches to web mapping and interactive cartography.
- Highlight new and noteworthy ArcGIS Maps SDK for JavaScript capabilities, particularly those introduced in versions 5.1 and 5.2.
- Demonstrate modern development patterns using map components.
- Provide developers with practical examples and reusable source code.
- Experiment with different visualization techniques, spatial interactions, and storytelling approaches.
- Participate in and learn from the global mapping community.
